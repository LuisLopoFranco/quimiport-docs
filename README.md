# QuimiPort - Gestão de Cargas Químicas

## Contexto
O porto de Santos é um dos principais polos logísticos do Brasil, movimentando diveros
tipos de produtos químicos que exigem rigoroso controle de segurança, documentação e
classificação de risco. O problema atual é a falta de um sistema unificado que integre
o cadastro de produtos, o registro de cargas, a validação de documentos obrigatórios e
o fluxo de liberação/ bloqueio, colocando em risco a segurança operacional e a conformidade
legal.

## Objetivo da Aplicação
Criar a base conceitual de uma solução full stack chamada **QuimiPort** para gerenciar
o ciclo de vida de cargas químicas. O sistema permitirá cadastrar produtos, registrar cargas,
controlar status (Registrada, Em Inspeção, Liberada, Bloqueada, Cancelada) e garantir que
nenhuma carga seja movimentada sem a devida documentação e autorização técnica.
